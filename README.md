# Clairvoyance Exhibits

Exhibits made with [Clairvoyance](https://www.clairvoyanceai.com): games, simulations, tools, and presentations. Each is a single `exhibit.json` holding its HTML, CSS, and JavaScript.

## Install

Install from the Clairvoyance **Gallery**, or copy a folder into the `exhibits/` folder in your Clairvoyance data folder (Windows: `%APPDATA%\clairvoyance\exhibits\`). It appears in the Exhibits sidebar.
